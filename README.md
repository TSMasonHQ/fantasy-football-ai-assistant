# Fantasy Football AI Assistant

Fantasy Football AI Assistant is a personal, single-user home-lab project for analyzing my Yahoo Fantasy Football league.

## Purpose

The application uses read-only Yahoo Fantasy Sports API data to support private fantasy football analysis, including:

- League settings
- Team rosters
- Standings
- Weekly matchups
- Player ownership and status
- Player statistics
- Lineup analysis
- Waiver-wire research
- Roster-depth analysis
- Matchup and player research

## Usage

This project is for personal use only.

It is not commercially distributed, is not offered as a public service, and is not intended for use by other users.

## Yahoo Fantasy Sports API

The application is designed to use Yahoo Fantasy Sports API access in read-only mode.

It does not attempt to:

- Add or drop players
- Submit waiver claims
- Change starting lineups
- Propose or accept trades
- Modify league settings

## Hosting

The application runs privately on a self-hosted Linux virtual machine in a home lab environment.

OAuth credentials, tokens, private league data, and other secrets are not stored in this public repository.

## Privacy and Security

No private Yahoo account credentials, OAuth tokens, league exports, or personal fantasy data are intended to be published here.

This repository exists primarily to document the application and its intended Yahoo Fantasy Sports API use case.
